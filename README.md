### 🚀 Проекты

**[My Cloud](https://github.com/backsty/my-cloud)** — облачное файловое хранилище
Единственный разработчик. Слоистая архитектура, 57 REST-операций на полностью асинхронном стеке, авторизация через Zitadel (OAuth 2.0 / OIDC / PKCE / JWT), фронтенд на React + Reatom по Feature-Sliced Design.
`Python` `FastAPI` `SQLAlchemy 2.0 async` `PostgreSQL` `React 19` `TypeScript` `Zitadel` `Docker`

**[Chaos Organizer](https://github.com/backsty/Chaos-Organizer-diploma)** — веб-мессенджер с ботом-органайзером
Реалтайм на WebSocket + SSE, офлайн-режим на Service Worker + IndexedDB, клиентское шифрование. Фронтенд без фреймворка — на чистом ES6.
`Node.js` `Koa` `WebSocket` `SSE` `JavaScript ES6` `PWA`

**[Pub/Sub мессенджер](https://github.com/backsty/messenger-lab4)** — реалтайм без брокера
Long polling через `DeferredResult`, иерархическая маршрутизация топиков, потокобезопасное in-memory хранилище.
`Java` `Spring Boot` `JavaFX` `Gradle`

**[Библиотека с QR-кодами](https://github.com/backsty/nstu-sixth-semester-main)** — полный цикл проектирования
Анализ предметной области → каталог требований → прототип → слоистая архитектура с элементами DDD. Шесть UML-диаграмм.
`Java` `JavaFX` `ZXing` `PlantUML`
